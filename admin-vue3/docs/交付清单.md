## 🚀 如何使用

### 快速开始（3 步）

#### 1️⃣ 导入
```typescript
import { useArticle } from '@/composables/useArticle'
```

#### 2️⃣ 使用
```typescript
const articleManager = useArticle()

const { list, total } = await articleManager.loadList({
  pageNum: 1,
  pageSize: 10
})
```

#### 3️⃣ 完成
```typescript
await articleManager.createArticle({
  title: '标题',
  content: '内容'
})
```
