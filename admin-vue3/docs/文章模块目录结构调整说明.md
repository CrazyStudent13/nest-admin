# 文章模块组合函数目录结构调整

## 📁 新的目录结构

```
src/composables/
├── post/                    # 文章模块相关组合函数
│   ├── index.ts            # 统一导出
│   ├── useArticle.ts       # 文章管理
│   └── useSubject.ts       # 专栏管理
├── useDict.ts
├── useForm.ts
├── useRequest.ts
└── ... (其他组合函数)
```

---

## 🔄 导入路径变更

### 之前
```typescript
import { useArticle } from '@/composables/useArticle'
import { useSubject } from '@/composables/useSubject'
```

### 现在
```typescript
// 方式1：分别导入
import { useArticle } from '@/composables/post/useArticle'
import { useSubject } from '@/composables/post/useSubject'

// 方式2：从索引文件导入（推荐）⭐
import { useArticle, useSubject } from '@/composables/post'
```

## 💡 使用示例

### 在 Vue 组件中使用

```vue
<script setup lang="ts">
// 推荐：从索引文件导入
import { useArticle, useSubject } from '@/composables/post'

const articleManager = useArticle()
const subjectManager = useSubject()
</script>
```

### 在 TypeScript 文件中使用

```typescript
import { useArticle } from '@/composables/post'
import type { UseArticleReturn } from '@/composables/post'

const articleManager: UseArticleReturn = useArticle()
```

## 🎯 优势

### 1. 更好的组织
- 相关文章和专栏的组合函数放在一起
- 便于管理和维护

### 2. 统一的入口
- 通过 `index.ts` 统一导出
- 导入更简洁

### 3. 清晰的模块划分
- `post/` 目录明确表示这是文章模块
- 与其他模块（如 system、monitor）区分开

### 4. 便于扩展
未来可以添加更多文章相关的组合函数：
```
src/composables/post/
├── useArticle.ts      # 文章管理
├── useSubject.ts      # 专栏管理
├── useCategory.ts     # 分类管理（未来）
├── useTag.ts          # 标签管理（未来）
└── index.ts           # 统一导出
```

## ⚠️ 注意事项

### 1. 类型导出
如果需要类型定义，可以从索引文件导入：

```typescript
import type { UseArticleReturn } from '@/composables/post'
```

### 2. 向后兼容
旧的导入路径已经不存在，需要全部更新为新的路径。

### 3. IDE 提示
如果 IDE 缓存了旧路径，可能需要重启 IDE 或清除缓存。

## 🔧 迁移步骤

如果你的项目中还有使用旧路径的地方：

### 步骤 1：全局搜索
```bash
# 搜索所有使用旧路径的文件
grep -r "@/composables/useArticle" src/
grep -r "@/composables/useSubject" src/
```

### 步骤 2：批量替换
```bash
# 替换 useArticle
find src/ -type f -name "*.ts" -o -name "*.vue" | xargs sed -i "s|@/composables/useArticle|@/composables/post|g"

# 替换 useSubject
find src/ -type f -name "*.ts" -o -name "*.vue" | xargs sed -i "s|@/composables/useSubject|@/composables/post|g"
```

### 步骤 3：验证
确保没有编译错误，功能正常。
