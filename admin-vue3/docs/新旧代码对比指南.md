# 新旧代码对比指南

本文档详细对比了使用 `useArticle` 组合函数前后的代码差异，帮助你理解重构的价值。

## 📊 总体对比

| 维度 | 旧代码 | 新代码 | 改进 |
|------|--------|--------|------|
| 代码组织 | 分散在组件中 | 集中在组合函数 | ✅ 更易维护 |
| 方法命名 | `getList`, `handleDelete` | `loadList`, `deleteArticle` | ✅ 更语义化 |
| 类型安全 | JavaScript，无类型 | TypeScript，完整类型 | ✅ 更安全 |
| 错误处理 | 不统一 | 统一处理 | ✅ 更健壮 |
| 可复用性 | 耦合 Vue 组件 | 平台无关 | ✅ 可跨框架 |
| 可测试性 | 难以测试 | 易于 mock | ✅ 易测试 |

## 🔍 详细对比

### 1. 导入方式

#### ❌ 旧代码
```javascript
import { listArticle, delArticle, getArticle } from '@/api/post/article'
import { ElMessage, ElMessageBox } from 'element-plus'
```

**问题**：
- 需要导入多个 API 函数
- 每个页面都要重复导入
- 没有统一的入口

#### ✅ 新代码
```typescript
import { useArticle } from '@/composables/useArticle'
```

**优势**：
- 单一导入，统一管理
- 所有方法都在一个对象上
- 清晰的命名空间

### 2. 加载文章列表

#### ❌ 旧代码
```javascript
const article = reactive({
  loading: true,
  list: [],
  total: 0,
  getList: () => {
    article.loading = true
    listArticle(article.query).then((res) => {
      article.list = res.data.list || []
      if (article.list && article.list.length > 0) {
        article.list.forEach((item) => {
          if (item.updateTime) item.updateTime = dayjs(item.updateTime).format('YYYY-MM-DD HH:mm:ss')
          if (item.createTime) item.createTime = dayjs(item.createTime).format('YYYY-MM-DD HH:mm:ss')
          if (item.publishTime) item.publishTime = dayjs(item.publishTime).format('YYYY-MM-DD HH:mm:ss')
        })
      }
      article.total = res.data.total || 0
      article.loading = false
    }).catch(() => {
      article.loading = false
    })
  }
})

// 调用
article.getList()
```

**问题**：
- ❌ 嵌套过深（Promise 链）
- ❌ 错误处理不完整
- ❌ 时间格式化逻辑重复
- ❌ 状态管理混乱

#### ✅ 新代码
```typescript
const articleManager = useArticle()
const loading = ref(false)
const list = ref<Article[]>([])
const total = ref(0)

const loadList = async () => {
  loading.value = true
  try {
    const { list: articles, total: totalCount } = await articleManager.loadList(query)
    
    // 格式化时间字段
    list.value = articles.map(item => ({
      ...item,
      updateTime: item.updateTime ? dayjs(item.updateTime).format('YYYY-MM-DD HH:mm:ss') : undefined,
      createTime: item.createTime ? dayjs(item.createTime).format('YYYY-MM-DD HH:mm:ss') : undefined,
      publishTime: item.publishTime ? dayjs(item.publishTime).format('YYYY-MM-DD HH:mm:ss') : undefined
    }))
    
    total.value = totalCount
  } catch (error) {
    console.error('加载文章列表失败:', error)
    ElMessage.error('加载文章列表失败')
  } finally {
    loading.value = false
  }
}

// 调用
await loadList()
```

**优势**：
- ✅ async/await 更清晰
- ✅ 统一的错误处理
- ✅ 状态管理分离
- ✅ 类型安全

### 3. 删除文章

#### ❌ 旧代码
```javascript
handleDelete: (row) => {
  const articleIds = row.id || row.articleId || article.ids
  const titles = row.title ? `"${row.title}"` : `选中的 ${article.ids.length} 篇文章`
  
  ElMessageBox.confirm(`是否确认删除文章${titles}？`, '系统提示', {
    confirmButtonText: '确定',
    cancelButtonText: '取消',
    type: 'warning'
  })
    .then(function () {
      return delArticle(articleIds)
    })
    .then(() => {
      article.getList()
      ElMessage.success('删除成功')
    })
    .catch(() => {})
}
```

**问题**：
- ❌ Promise 链嵌套
- ❌ 错误被静默忽略
- ❌ 逻辑耦合在 reactive 对象中

#### ✅ 新代码
```typescript
const handleDelete = async (row?: Article) => {
  const deleteIds = row?.id || row?.articleId || ids.value
  
  if (!deleteIds || (Array.isArray(deleteIds) && deleteIds.length === 0)) {
    ElMessage.warning('请选择要删除的文章')
    return
  }

  const titles = row?.title ? `"${row.title}"` : `选中的 ${ids.value.length} 篇文章`
  
  try {
    await ElMessageBox.confirm(`是否确认删除文章${titles}？`, '系统提示', {
      confirmButtonText: '确定',
      cancelButtonText: '取消',
      type: 'warning'
    })
    
    await articleManager.deleteArticle(deleteIds)
    ElMessage.success('删除成功')
    
    // 刷新列表
    await loadList()
  } catch (error) {
    if (error !== 'cancel') {
      console.error('删除文章失败:', error)
      ElMessage.error('删除失败')
    }
  }
}
```

**优势**：
- ✅ async/await 扁平化
- ✅ 完整的错误处理
- ✅ 参数验证
- ✅ 区分取消和错误

### 4. 创建文章

#### ❌ 旧代码
```javascript
// 在 ArticleForm 组件中
addArticle(submitData).then((res) => {
  ElMessage.success('新增成功')
  open.value = false
  resetForm()
  emit('success')
})
```

**问题**：
- ❌ 没有错误处理
- ❌ 魔法字符串
- ❌ 回调地狱

#### ✅ 新代码
```typescript
const handleCreate = async () => {
  try {
    const newArticle = await articleManager.createArticle(formData)
    ElMessage.success('新增成功')
    
    // 关闭表单
    open.value = false
    resetForm()
    
    // 通知父组件
    emit('success')
    
    // 返回新文章 ID
    return newArticle.id
  } catch (error) {
    console.error('创建文章失败:', error)
    ElMessage.error('创建失败')
    throw error
  }
}
```

**优势**：
- ✅ 完整的错误处理
- ✅ 可以返回值
- ✅ 易于调试

### 5. 获取文章详情

#### ❌ 旧代码
```javascript
form: {
  handleUpdate: (row) => {
    const articleId = row.id || row.articleId || article.ids
    getArticle(articleId).then((res) => {
      article.form.data = res.data
      article.form.open = true
      article.form.title = '修改文章'
    })
  }
}
```

**问题**：
- ❌ 嵌套在 reactive 对象中
- ❌ 没有错误处理
- ❌ 职责不清（获取数据 + UI 控制）

#### ✅ 新代码
```typescript
const handleUpdate = async (row: Article) => {
  const articleId = row.id || row.articleId
  
  if (!articleId) {
    ElMessage.warning('文章ID不存在')
    return
  }

  try {
    const detail = await articleManager.getDetail(articleId)
    
    // 返回详情数据，由调用方决定如何使用
    return detail
  } catch (error) {
    console.error('获取文章详情失败:', error)
    ElMessage.error('获取文章详情失败')
    throw error
  }
}

// 调用方
const detail = await handleUpdate(row)
if (detail) {
  formData.value = detail
  open.value = true
}
```

**优势**：
- ✅ 职责分离
- ✅ 完整的错误处理
- ✅ 更灵活的使用方式

## 💡 最佳实践

### 1. 错误处理

```typescript
// ✅ 推荐
try {
  await articleManager.createArticle(data)
  ElMessage.success('创建成功')
} catch (error) {
  ElMessage.error('创建失败')
  console.error(error)
}

// ❌ 避免
articleManager.createArticle(data).then(() => {
  ElMessage.success('创建成功')
}).catch(() => {
  // 空 catch
})
```

### 2. 加载状态

```typescript
// ✅ 推荐
const loading = ref(false)

const handleSubmit = async () => {
  loading.value = true
  try {
    await articleManager.updateArticle(data)
  } finally {
    loading.value = false
  }
}

// ❌ 避免
const handleSubmit = () => {
  loading.value = true
  articleManager.updateArticle(data).finally(() => {
    loading.value = false
  })
}
```

### 3. 类型使用

```typescript
// ✅ 推荐
import type { Article, ArticleQueryParams } from '@/types/api'

const query: ArticleQueryParams = {
  pageNum: 1,
  pageSize: 10
}

// ❌ 避免
const query = {
  pageNum: 1,
  pageSize: 10
  // 没有类型检查
}
```
